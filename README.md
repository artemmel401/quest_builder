# Конструктор квестов

Для запуска приложения скопировать содержимое файла .env.example в файл .env и заполнить все поля

Для запуска приложения для тестов:

```bash
npm run dev
```

Для деплоя запустить команду:

```bash
docker compose up -d --build
```

По адресу [http://localhost:3000](http://localhost:3000) будет запущено приложение.
